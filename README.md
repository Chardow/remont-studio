# Ремонт Студио – нова версия на сайта

Изграден наново статичен сайт (30 страници) за „Ремонт Студио“ – ремонти на жилища във Варна. Отстранява проблемите, открити при прегледа на оригинала (https://konkurs-zadacha.vercel.app/).

- Без външни зависимости: HTML, CSS и JavaScript, генерирани от `src/build.mjs` (Node 18+).
- Сайтът работи и без JavaScript: скриптовете само подобряват менютата, плъзгача, калкулатора и формата.
- Шрифтът Inter (OFL) се зарежда от собствения сървър, без Google Fonts и без бисквитки.

## Стартиране

```bash
npm run build      # генерира dist/
npm run preview    # build + локален сървър на http://localhost:4173
```

Публикуван адрес: https://remont-studio-ten.vercel.app/

Vercel използва `vercel.json`: `node src/build.mjs` → `dist/`, плюс функцията `api/zapitvane.js`.

## Структура

| Път | Какво е |
| --- | --- |
| `src/build.mjs` | Генерира всички страници, sitemap.xml и robots.txt |
| `src/layout.mjs` | Обща рамка: head/SEO, хедър, мобилно меню, футър |
| `src/content/` | Текстовете на услугите, стъпките, обектите и блога |
| `src/plan.mjs` | SVG схема на апартамента със „старо/ново“ състояние на всеки слой |
| `src/art.mjs` | Икони и илюстрации |
| `public/assets/js/cena.js` | Формулата за ориентировъчна цена (обща за конструктора и началната страница) |
| `api/zapitvane.js` | Приема формата за запитване, проверява данните на сървъра |

## Изпращане на запитванията по имейл

Задайте във Vercel → Settings → Environment Variables:

- `RESEND_API_KEY` – ключ от resend.com
- `ZAPITVANE_TO` – имейл, на който да пристигат запитванията
- `ZAPITVANE_FROM` (по желание) – подател, напр. `Ремонт Студио <zapitvane@domein.bg>`

Без тях формата работи в демо режим: проверява данните и показва потвърждение с бележка, че нищо не е изпратено.

## Какво трябва да се смени преди истинско пускане

- Телефон, имейл, ЕИК и работно време в `src/layout.mjs` (`SITE`) и банерът „Демо версия“.
- Илюстрациите на завършените обекти – с реални снимки.
- Отзивите – с реални имена или връзка към Google отзиви.
